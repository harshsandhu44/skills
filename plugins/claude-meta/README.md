# claude-meta

Skills for steering Claude itself.

| Skill | What it does |
| ----- | ------------ |
| `write-a-skill` | Author new skills with proper structure and progressive disclosure. |
| `grill-me` | Interview you about a plan until the decision tree is resolved. |
| `hand-off` | Compact the conversation into a handoff doc for another agent. |
| `caveman` | Ultra-compressed communication mode. |
